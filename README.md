## 🚀 How to Run the Programs

### 1. Clone the Repository

```bash
git clone https://github.com/Chaki34/Cognifyz-C-Cpp-Programming-Internship.git
```

### 2. Navigate to a Task Folder

For example:

```bash
cd "Cognifyz-C-Cpp-Programming-Internship/Task 10 – Simple Inventory Management System"
```

### 3. Compile the C Program

Make sure GCC is installed and configured in your system PATH.

```bash
gcc main.c -o inventory-system -std=c11 -Wall -Wextra
```

### 4. Execute the Program

**Windows PowerShell:**

```powershell
.\inventory-system.exe
```

**Linux / macOS:**

```bash
./inventory-system
```

> **Note:** Each task contains its own `main.c` source file. Repeat the compilation process inside the respective task directory.
